# Remote Sensing Fall 2026 Final Project

## Abstract
Project repo for remote sensing fall 2026 class.

My project goal is to compare Disko Bay across different years to compare low vs high melt years and to be able to connect this data with my own modeling domain and outputs for comparison. The years I aim to use are (2018, 2019, 2020, 2021). 

## Datasets
I aim to use the following datasets:
- MODIS / Aqua Terra SST 
- SMAP SSS 
- Sea Ice Concentration from NSIDC


## Figures 
I will create the following figures:
- Time series of SST and SSS for Disko Bay across the years 2018-2021
- Sea ice concentration maps for Disko Bay for the same years
- compare these same datasets with MITgcm model outputs
